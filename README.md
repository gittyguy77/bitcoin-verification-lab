# Bitcoin Verification Lab

Don't trust. Verify.

An interactive guide that walks through Bitcoin's core claims — supply cap, immutability, decentralization, seed phrase security, censorship resistance — using real code, math, and live network data. No prior technical background required.

## Contents

- `bitcoin-verification-lab.html` — Interactive version (runs in any browser)
- `bitcoin-verification-lab.md` — Full documentation in Markdown format

## Documentation

The Markdown file covers 11 verification experiments. Each experiment includes:

1. The claim being tested
2. The actual Bitcoin source code or math behind it
3. Step-by-step verification instructions
4. A ready-to-use AI prompt to double-check the work independently
